# Exploratory Data Analysis

A practical exploratory data-analysis module for understanding distributions, relationships, anomalies, and useful patterns before model building.

## Purpose

This repository is part of a structured data-science learning series. Its goal is to document practical skills clearly and keep the corresponding notebook easy to review.

## Topics Covered

- Descriptive statistics
- Univariate and multivariate exploration
- Distribution analysis
- Correlation and relationship analysis
- Data visualization and interpretation
